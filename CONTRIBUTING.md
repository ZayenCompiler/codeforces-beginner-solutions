# Contributing

This repository is intended to help beginners learn competitive
programming through Codeforces problems.

Contributions are welcome, especially improvements to explanations.

## Good Contributions

- Clearer explanations
- Better algorithmic reasoning
- Complexity analysis
- Corrections
- Alternative approaches
- Typo and formatting fixes

## Explanation Guidelines

A problem explanation should preferably contain:

1. Problem idea
2. Key observation
3. Algorithm
4. Why the algorithm works
5. Complexity
6. C++ implementation

Please do not copy the complete Codeforces problem statement.
Link to the original problem instead.
